# Logo assets

Drop your logo files in this folder using these exact names and both pages
will pick them up automatically — no HTML changes needed.

| File | Used where | Notes |
|---|---|---|
| `exe-hero-logo.png` | `index.html` hero, full-width area above the buttons | Transparent PNG recommended. It's centered and capped at 440px tall, fades into the background at the bottom. |
| `logo-mini.png` | Top nav + footer on both `index.html` and `rebloxed.html` | Small, roughly square (e.g. 128×128 or 256×256), transparent PNG. Fills a 34px rounded box. |

If a file is missing, the page quietly falls back to a placeholder mark
instead of showing a broken image icon — so it's safe to preview before
the real logos are in place.
